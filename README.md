# gchaldu

Configura los agentes de código que ya usás (Claude Code y OpenCode) para trabajar en proyectos Java/Spring con tus reglas, tu forma de trabajar y tus guardas de seguridad.

```
gchaldu install
```

> Estado: en construcción. Todavía no hay una versión para instalar.

## Qué va a hacer

- Instalar en cada agente una forma de trabajar: explorar antes de escribir, planificar antes de codear y cerrar con evidencia.
- Instalar skills de Java/Spring según la arquitectura del proyecto: por feature con capas o hexagonal.
- Configurar permisos seguros y servidores MCP (Context7 y DeepWiki).
- Funcionar en macOS, Linux y Windows.
